C is one of those languages where a decades-old book is likely to *still be usable and relevant*. Imagine trying to learn Unity and C# off a 15-year-old book on *that* engine...

# Coding C: Introductory
Note that introductory doesn't mean *easy*.

- Brian W. Kernighan and Dennis M. Ritchie. *The C Programming Language*, 2nd ed. (ANSI C). This seems to be a love-it-or-hate-it text; I rather like it, but I'm doing this as a hobbyist, and it *is*, at times, terse to the point of being telegraphic. One is clearly required to go away and *think* about the problems posed. **in progress**

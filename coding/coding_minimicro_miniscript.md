# Mini Micro
I chanced on this while looking for a lighter-weight game engine to put on a Clockwork Pi uConsole!

- [Mini Micro](https://miniscript.org/MiniMicro/#about), "a neo-retro virtual computer."

**Specifications:**
- 960 x 640 full-color (32-bit) display
- pixel, sprite, and tile graphics
- 68 x 26 text display
- synthesized and digitized stereo sound
- keyboard, mouse, and game controller input
- interactive REPL (read/eval/print loop)
- built-in code editor
- code in [MiniScript](https://miniscript.org), a clean, modern language

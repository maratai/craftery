I started learning Lua basics thanks to the free/open-source [Defold 2D game engine](https://defold.com/), which is under active development and a lot of fun; but I speak as a hobbyist.

# Lua for Beginners
- Steven Gellis. *50 Lua Programming Exercises: Complete Lua Concepts Covered in Details* [sic]. Excellent, concise overview. I only made it partway through the "intermediate" exercises but it's clearly written and a lot of fun. **Recommended**.
- Steven Gellis. *Lua Programming Ultimate Guide*. ALso aimed toward beginners, and a useful reference alongside Gellis's *50 Lua Programming Exercises* and the [official Lua](https://lua.org/) documentation.
- Julian Lornfeld. *Lua Programming: The Ultimate Resource for BEginners and Advanced Mastery for Beginner Programmers*. I haven't worked through this yet.
- Evan Rhodes. *The Complete Lua Programming Guide: Create Games, Apps, and Scripts with Hands-on Projects*. I haven't worked through this yet; note that this has an unusually large font size.

# Lua References
- Roberto Ierusalmischy. *Programming in Lua*, 4th ed. 2016. Beautifully written and organized. **Recommended**.

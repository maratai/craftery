Forth is my current hobby programming language.

# Forth: Books
- Leo Brodie. *Starting FORTH*. An excellent introduction; note that it explains things that one normally assumes as general knowledge for English-speaking computer-using adults (the RETURN key, for instance). [Available online as well as for free PDF download](https://www.forth.com/starting-forth/). **Recommended**. **currently reading**
- Leo Brodie. *Thinking FORTH: A Language and Philosophy for Solving Problems*. **to-read**
